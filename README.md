## Hanbot core for League of Legends

📝 Notes
This repository is separate from the Aura project but complements it by providing the necessary core library.

⚠️ Version Support
This project was supported only up to *League of Legends version 14.8.578.3867*. For future versions of the game, a separate solution is required to maintain full functionality.
